# Security Policy

## Reporting Security Vulnerabilities

We value the security and privacy of students and educational institutions using Virtual Science Lab.

To report a vulnerability:
- Please email the maintainer directly at: `yashpatadiya1724@gmail.com`
- Include a description of the issue, affected endpoints or files, and proof-of-concept steps.
- We aim to review and acknowledge all disclosures within 48 hours.
- Please do not file public GitHub issues for unresolved security vulnerabilities.
