# Contributing to Virtual Science Lab

We welcome contributions to the 3D physics/chemistry simulations, WebXR camera controls, and educational quizzes.

## Guidelines
1. **Lightweight Assets**: Prefer procedural geometry over large binary 3D assets to keep load times fast for low-bandwidth school networks.
2. **No Secrets**: Never commit real database URLs or session secrets.
3. **Responsive & Fallback**: Ensure all simulations work smoothly via standard mouse/touch before adding WebXR enhancements.
4. **Branching**: Submit changes via pull requests from feature branches, never directly to `main`.
